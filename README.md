# Sales Data Analysis

##  Project Objective
This project analyzes sales data using Python and Pandas to identify trends and calculate total sales.
Tools Used
- Python
- Pandas
  
Dataset
The dataset contains:
- Product names
- Sales values

Analysis Performed
- Total sales calculation
- Sales grouped by product
- Data organization using Pandas
  
Results
The analysis identified:
- Total revenue generated
- Best-performing products
